# Codex Instructions

- Build and maintain this project as a premium dark luxury fintech analytics dashboard.
- Prioritize clean UI, responsiveness, modular architecture, and evaluator-facing polish in every change.
- Do not generate giant monolithic files; split work into focused modules.
- Prefer reusable components over one-off implementations.
- Keep TypeScript strict and use explicit, reliable types.
- Derive analytics, KPIs, and aggregates from application state or data sources instead of hardcoding values.
- Role-based UI is frontend-only and must support both `Viewer` and `Admin`.
- All required features must be present.
- Optional features must also be present: dark mode, persistence, mock API, animations, CSV/JSON export, and advanced filtering.
- Always preserve the existing design system, visual hierarchy, and spacing consistency.
- After each task, summarize which files changed and what work remains.
